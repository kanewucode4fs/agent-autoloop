# Agent Autoloop 文档总索引

Agent Autoloop 让命令行 Agent 在后台接活并持续跟进；只有需要本人决定时才发卡片。本项目处于 `iteration`（增量交付期）。

本文档集以仓库当前实现为依据。中控页面是下一阶段的目标，当前可用入口是命令行、HTTP、MCP 和通道卡片。文档中的“事项结束”和“一轮结束”含义不同，先读[状态与转换](state-machines.md)。
